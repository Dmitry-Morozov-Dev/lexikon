# Учебные функции: контекст из книг, ввод, покрытие книги, фразы, трудные слова

Коротко: что изучено у аналогов и что решили. Пользовательский замысел сохранён; отступления помечены «≠».

## 1. Контекст из книги на карточке (+ подсказка-пропуск)
**Аналоги.** Lingvist и Clozemaster учат слово только внутри предложения-пропуска; Clozemaster даёт подсказку
«первая буква» за половину очков. LingQ/Readlang/Language Reactor/Migaku сохраняют исходное предложение вместе
с источником (Migaku: «sentence card» с выделенным словом).
**Решения.**
- У слова из книги хранится список контекстов `contexts[] = {en, ru, docId, bookTitle, ch, para, at}` (до 8).
  Повторное долгое нажатие на то же слово в другом месте книги дописывает новое предложение.
  У старых карточек контекст берётся из `contextSentence` (миграция не нужна).
- В «Показать» блок «📖 Из книги»: предложение (слово подсвечено, с учётом форм: considered → consider,
  went → go, gave up → give up), перевод RU, название книги. Контексты собираются **по всем книгам** для этой
  леммы, а также показываются у слова из обычной колоды, если оно встречалось в книге.
- Пропуск на лицевой: после первого свайпа влево (lapses > 0) на лицевой под словом — предложение, где слово
  заменено на «＿＿＿» по длине слова (как просил пользователь: слово видно + приписка-пропуск).
  После «Показать» пропуск заполняется подсвеченным словом и переводом.
- ≠/расширение: пропуск применяется и к словам из колод (берём пример из колоды, где нашлась форма слова) —
  у колод почти всегда есть примеры, а приём одинаково полезен. На обратной (RU) стороне тот же пропуск —
  это хорошая подсказка для вспоминания EN-слова (как Lingvist).

## 2. Ввод слова на обратной карточке (RU → EN)
**Аналоги.** Lingvist: ввод с побуквенной подсветкой ошибок, но опечатка = ошибка (частая жалоба на телефоне).
Clozemaster: «spelling hints» — сообщает, если ошибся на 1 букву. Quizlet Learn: можно «засчитать» свой ответ.
**Решения.**
- Ввод появляется, когда карточка уже уходила влево (lapses > 0) и выпала обратной стороной (как сейчас, ~45%;
  у трудных слов чаще). Отключается в настройках.
- Поле: `autocapitalize=off autocorrect=off spellcheck=false enterkeyhint=done`, шрифт 16px+ (iOS не зумит).
- Проверка: регистр, пробелы, апострофы, артикль (a/an/the), «to» у глаголов, варианты через `/ , ;`,
  BrE/AmE (colour/color, -ise/-ize, -yse/-yze, centre/center, travelled/traveled, catalogue/catalog).
- Опечатка: расстояние Дамерау–Левенштейна ≤ 1 при длине ≥ 5 (≤ 2 при ≥ 10) → «Почти» (оценка «Трудно»).
  ≠ Lingvist: опечатку не считаем провалом — меньше фрустрации на телефоне, но интервал не растёт как за «Хорошо».
- Верно → «Хорошо», «Почти» → «Трудно», неверно / «Не знаю» → «Снова». После проверки раскрывается «Показать»
  с побуквенной подсветкой; кнопка «Дальше» применяет оценку, свайп/кнопки оценок позволяют её переопределить
  (как «засчитать» в Quizlet).
- Пока фокус в поле, свайпы и удержание не срабатывают; при открытой клавиатуре поле прокручивается в видимую
  область (visualViewport).

## 3. Процент знакомых слов в книге
**Аналоги.** LingQ показывает «% новых слов» по **уникальным** словам — на форуме это критикуют: не отражает
понимание текста. Правильная метрика «покрытия» — доля **всех словоупотреблений**; 95–98% — порог комфортного
чтения (Nation; часто цитируется у LingQ/Readlang/LingoBlend).
**Решения.**
- Показываем покрытие по словоупотреблениям: «знакомо ~N% слов текста», плюс «уникальных слов» и
  «незнакомых уникальных». Подсказка (ⓘ) честно объясняет расчёт.
- «Знакомое» слово: в любой колоде в состоянии «выучено» (known), «повторение» (review) или «убрано» (hidden),
  а также ~200 служебных слов (the, of, and, I'm…). Не знакомо: новые, на изучении, сохранённые из книг.
  Имена собственные (слова только с заглавной) не учитываются вовсе.
- Лемматизация: правила английских окончаний + список неправильных форм (общий `lemma.js`).
- Частоты слов книги считаются в Web Worker один раз и кэшируются в IndexedDB (`bookStats`); проценты
  пересчитываются при открытии «Книг», если изменились знания (сигнатура). Лента не затрагивается.
- Бонус: «Частые незнакомые слова» книги (топ-30) с кнопкой «＋» — добавляет слово в колоду книги с примером
  из книги.

## 4. Сохранение фраз в читалке
**Аналоги.** LingQ (iOS): удержание слова и протягивание по соседним словам; если протягивание ненадёжно —
удерживать первое слово и тапать последнее. Пользователи жалуются на выделение через перенос строки.
Readlang: выделение фразы в пределах страницы.
**Решения.**
- Два способа: (а) удержать слово и, не отпуская, вести палец по словам — подсветка растёт; (б) в пузырьке
  кнопка «＋ Фраза» → тап по последнему слову фразы. Работает через перенос строки (выделение по словам
  абзаца, а не по системному выделению), до 8 слов, в пределах абзаца.
- Одиночное долгое нажатие работает как раньше. Если удержание переросло во фразу, только что созданная
  одиночная карточка удаляется.
- Фраза ищется в колодах (phrasal/idioms/colloc) с учётом форм (gave up → give up); иначе перевод фразы +
  предложения. Карточка в колоду книги, сохранённые фразы подчёркиваются в тексте.

## 5. Трудные слова (leeches)
**Аналоги.** Anki: «leech» после 8 провалов в повторении, затем предупреждение каждые 4; по умолчанию метка,
приостановка — опция. Совет Anki: интерференция похожих слов (disappoint/disappear) — учить по одному;
переписать карточку, добавить мнемонику.
**Решения.**
- ≠ Anki 8: порог **4 провала после того, как слово уже вспоминалось** (повторение/шаги обучения пройдены
  хотя бы раз), отдельный счётчик `relapses`. В приложении шаги короткие, а слово легко уходит в «Снова» много
  раз подряд в первый день — это не «пиявка». Для старых данных: lapses ≥ 6.
- Значок «трудное» на карточке; в «Показать» блок подсказки: своя мнемоника (поле, сохраняется в прогрессе —
  работает и для слов из колод), заметка, контекст из книги, **похожие слова** из колод (интерференция),
  разбор по морфемам (префиксы/суффиксы).
- Доп. тренировка: у трудных слов чаще обратная сторона (70%) и ввод, пропуск на лицевой.
- Список «Трудные слова» в «Колодах»: сбросить счётчик, убрать из ленты — только по выбору пользователя,
  без автоприостановки.
