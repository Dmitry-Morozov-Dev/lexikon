# Книги (библиотека + ридер) — дизайн

## Что подсмотрели у аналогов
- **Readest / Foliate (foliate-js)**: одна внутренняя модель книги для всех форматов (EPUB, FB2, TXT, PDF…); рендер
  по секциям (главам), а не всей книги; позиция хранится как якорь на элемент/диапазон (CFI), а не пиксели —
  поэтому переживает смену шрифта. Пагинация через CSS multi-column медленная и капризна в WebKit.
- **KOReader / Moon+ / FBReader / ReadEra**: настройки «Aa» (шрифт, кегль, интерлиньяж, поля, выравнивание),
  темы день/сепия/ночь, тап по центру — показать/скрыть панели, тап по краям — листание,
  оглавление и закладки в боковой панели, «осталось ~N мин».
- **Apple Books / Google Play Книги**: «Продолжить чтение» сверху библиотеки, обложки (или сгенерированная
  обложка с названием), прогресс на плитке, сортировка «недавние / название».
- **LingQ / Readlang**: импорт DRM-free EPUB/TXT/PDF/DOCX в «урок/книгу», тап по слову → перевод + фраза,
  слово попадает во флэш-карты конкретной книги; сохранённые слова подсвечены в тексте.
  DRM-книги и сканы без OCR — явная ошибка с объяснением.

## Решения
- Отдельная вкладка **«Книги»** (бывшие «Тексты PDF»). Код книг грузится лениво (`books/*.js` подключаются
  только при открытии вкладки/импорта), парсеры и `lib/` (pdf.js, JSZip) — только при импорте.
  Лента «Сегодня» книжный код не исполняет.
- Внутренняя модель: `documents` (IDB) — лёгкие метаданные книги (title, author, format, cover, toc, позиция,
  прогресс, закладки, participate); `bookContent` — главы `{title, paras[]}`. Миграция DB v2→v3 переносит
  старые PDF-тексты в главы. Лента читает только метаданные (participate) — книги её не замедляют.
- Форматы: PDF (pdf.js, сборка абзацев, удаление колонтитулов и номеров страниц, оглавление из outline),
  EPUB (container → OPF → spine, оглавление nav/NCX, обложка, детект DRM), FB2 / FB2.ZIP, TXT (UTF-8/UTF-16/
  cp1251/cp1252, главы по «Chapter N», Gutenberg-шапка), HTML, DOCX (заголовки по стилям), MD, RTF.
  MOBI/AZW3 — нет (совет: конвертировать в EPUB через Calibre).
- Рендер одной главы; очень длинные главы при импорте делятся на части (~5000 слов) — быстро на iPhone.
- Пагинация: «Прокрутка» (непрерывно внутри главы) и «Страницы» (тап по краям листает на экран). CSS-колонки
  не используем — ненадёжны в iOS Safari и ломают long-press.
- Позиция: `{ch, para, frac}` — глава + абзац + доля абзаца; сохраняется при скролле (throttle),
  `visibilitychange`/`pagehide`; восстанавливается после смены шрифта.
- Long-press по слову — как раньше (перевод слова и предложения, авто-добавление в колоду книги
  `pdf:<id>`, данные из Лексикона). Тап по подчёркнутому слову снова показывает пузырёк.
