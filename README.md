# Лексикон

Статический PWA-тренажёр английской лексики (EN → RU) до уровня **C1**.  
Без аккаунтов, рекламы и бэкенда. Прогресс в IndexedDB, настройки в localStorage.

## GitHub Pages

1. Создайте публичный репозиторий и залейте содержимое этой папки в **корень** ветки `main`  
   (файл `index.html` должен быть в корне репозитория).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)`.
3. Откройте `https://<user>.github.io/<repo>/`.

Локально: любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 8080
```

`file://` не рекомендуется (service worker и fetch колодятся ограничены).

## Установка на iPhone

1. Откройте сайт в **Safari**.
2. Кнопка **Поделиться** → **На экран «Домой»**.
3. Запускайте «Лексикон» с домашнего экрана (режим standalone).

**Важно:** Safari может очистить данные сайта. Делайте **резервную копию** в разделе «Настройки» → «Экспорт JSON».

## Картинки и офлайн

- Оболочка приложения и уже загруженные JSON кэшируются service worker’ом.
- **Картинки из интернета** подгружаются при первом показе карточки и **не** прекэшируются пакетом.
- Офлайн для картинок: только если браузер уже сохранил их в кэше HTTP, либо локальные SVG (`/icons/concepts/…`), либо буквенный градиент.
- Битая ссылка на изображение не ломает карточку — показывается запасной вариант.

## Колоды (`data/*.json`)

Список колод — в `decks.json`. Каждая колода указывает путь к JSON.

Формат файла колоды — массив карточек или `{ "cards": [ ... ] }`:

```json
{
  "id": "a1-0001",
  "word": "apple",
  "lemma": "apple",
  "ipa": "/ˈæpl/",
  "pos": "noun",
  "level": "a1",
  "tr": "яблоко",
  "note": "",
  "ex": "I eat an apple.",
  "exRu": "Я ем яблоко.",
  "colloc": "",
  "img": "/icons/concepts/nature.svg",
  "imgSrc": "svg",
  "imgAlt": "apple"
}
```

Если файла колоды ещё нет, приложение **не падает**: колода серая и недоступна, остальные работают.

Чтобы добавить данные: положите JSON в `data/`, убедитесь, что путь есть в `decks.json`, закоммитьте и обновите Pages.

## Возможности

- SM-2: Снова / Трудно / Хорошо / Легко
- Лимит новых карточек в день: 10 / 20 / 40 / ∞
- Сегодня: сначала повторы, затем новые из выбранных колод
- Поиск, правка и удаление своих карточек
- Импорт CSV: `word,ipa,tr,ex,exRu,level,img`
- Экспорт/импорт полного JSON-бэкапа IndexedDB
- Статистика: серия дней, карта 14 дней, изучено, due на завтра
- Тёмная и светлая темы
- TTS через Web Speech API (`en-US`), если доступен

## Лицензия данных

Собранная лексика — учебный набор, не копия коммерческих списков (Quizlet, ReWord, Oxford 3000 и т.п.).  
Используйте на свой страх и риск для личного обучения.
